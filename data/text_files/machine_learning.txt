Machine Learning Introduction
Machine Learning is a technology that enables computers to learn patterns from data and use those patterns to make predictions or decisions.


-Types of Machine Learning
1.Supervised Learning
Model learns from labeled data.
Example: Predicting house prices, student results.
2.Unsupervised Learning
Model finds patterns or groups in data without labels.
Example: Customer segmentation.
3.Reinforcement Learning
Model learns through rewards and penalties.
Example: Game-playing AI and robotics.
